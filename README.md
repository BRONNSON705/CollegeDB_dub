# CollegeDB

Веб-приложение для управления студентами и учебными группами.

## Технологии

- C# и .NET 10
- ASP.NET Core Minimal API
- HTML, CSS и JavaScript
- Microsoft SQL Server
- ADO.NET (Microsoft.Data.SqlClient)
- Swagger для проверки API

## Возможности

- Просмотр, добавление, редактирование и удаление студентов
- Создание и удаление учебных групп
- Проверка вводимых данных
- Связь студентов с учебными группами
- Хранение данных в Microsoft SQL Server

## Запуск

1. Установите .NET SDK 10 и Microsoft SQL Server.
2. Настройте строку подключения к базе данных.
3. Откройте терминал в папке CollegeDB.API.
4. Выполните команду dotnet run.
5. Откройте локальный адрес, указанный в терминале.

## База данных

Основные таблицы: Students и Groups.
Для связи студентов с группами используется внешний ключ GroupId.

## Назначение

Учебный проект для управления студентами и учебными группами.
